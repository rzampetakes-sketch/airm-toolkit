# B2B Partner Portal (Phase 2)

Next.js app for travel agencies/corporate desks booking on behalf of
clients: company-scoped `User`s (see `Company` model), consolidated
invoicing, and agent-facing search/booking flows that reuse the same
`apps/api` endpoints as `apps/web`, gated by `role: b2b_agent`.

Not scaffolded yet — build once B2C MVP (`apps/web`) is live.
